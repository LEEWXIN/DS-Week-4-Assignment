# DS Week 4 Assignment - Data Processing in Python

## Overview
This assignment consists of two parts analyzing COVID-19 data.

## Part 1 - COVID-19 Spread Modelling
- Plot Rt graphs for 6 countries (US, India, Brazil, UK, Germany, Australia)
- Correlation between deaths/recoveries and infected cases
- Disease duration analysis (~14 days based on India data)
- Fatality rate changes over time

## Part 2 - COVID-19 Papers Analysis
- Co-occurrence matrix of 10 medications from CORD-19 dataset
- Heatmap visualization of medication co-occurrence
- Chord diagram (Stretch Goal)
- Dosage extraction using regex (Stretch Goal)

## Dataset
- Part 1: Johns Hopkins COVID-19 data (loaded directly in notebook)
- Part 2: CORD-19 Research Challenge dataset from Kaggle

## How to Run
1. Open notebooks in Google Colab
2. For Part 2, upload `metadata.csv` from [CORD-19 Kaggle dataset](https://www.kaggle.com/datasets/allen-institute-for-ai/CORD-19-research-challenge)
3. Run all cells
